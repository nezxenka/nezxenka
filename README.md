### About me

I'm a 17-year-old developer from Shchyolkovo, Russia. I've been writing code since early 2023 and have tried a lot of things along the way: Minecraft server plugins, Telegram bots, network tools like proxies and protocol parsing, and a bit of 3D in ActionScript.

These days I mostly build websites and platforms end to end, from the interface to the backend. I care about things being fast and reliable.

- Building hosting for game and virtual servers with a user dashboard and admin panel
- Making donation shops and websites for Minecraft servers
- Frontend with TypeScript, React, Next.js and Tailwind, backend with Bun, Node.js, PostgreSQL and Redis
- Learning Go right now, and digging into C# and Rust in my free time
- Open to interesting projects and offers, message me on [Telegram](https://t.me/nezxenka)
